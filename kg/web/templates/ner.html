Başka makinede (GPU) eğittiğin modeli yükle
  1. 2. adımdaki "Colab not defterini indir" ile …-gliner-colab.ipynb dosyasını indir (veri seti ve ayarlar içinde).
  2. Google Colab'da Dosya → Not defteri yükle ile aç, Çalışma zamanı → Çalışma zamanı türünü değiştir → T4 GPU, sonra Çalışma zamanı → Tümünü çalıştır.
  3. Son hücre model.zip'i indirir; onu aşağıdan yükle. Sonra 4. adımda "Uygula".

Kendi GPU'lu bilgisayarında: train_gliner.py ve "GLiNER eğitim biçiminde indir" dosyasını indir, pip install gliner==0.2.29 accelerate sentencepiece protobuf, sonra python train_gliner.py dosya.json --epochs 5 --out model. Betiği bir sayfadan kopyalayıp yapıştırma: bazı görüntüleyiciler boşlukları "·" olarak kopyalar ve Python "invalid character '·'" hatası verir.

Türleri veya GLiNER etiketlerini değiştirirsen eğitim dosyasını yeniden indirip yeniden eğit.
